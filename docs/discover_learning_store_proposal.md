# Lumina 发现页重构提案：B 风格学习书店

日期：2026-09-08
状态：设计方向与功能范围已确认；已按用户提供正文整理 18 阶段书目，具体版本与资源可用性待核验。

## 最新范围修正（以此为准）

用户确认 Zero to Hero 只占发现页首页主专题，其 18 阶段和哲学主题放在专题详情，不作为全站分类、起点选择或默认搜索范围。

首页顺序固定为：主专题 → 适合你的起点（独立水平自选与试读）→ 按难度探索（估算/已复核分开）→ 目标与兴趣书单（第一次读完、短篇入门、悬疑故事横向陈列）→ 全部书库与搜索。

全站书库包含普通书目、试读内容与专题书目。专题署名只出现在专题详情；全站不得称为“向老师书单目录”。新版 Web 的 3 篇原创试读使用明确的演示估算标签，不代表已经运行评级或完成人工复核。已复核内容为空时显示真实空态。

## 1. 已确认决策

- 采用 B「编辑杂志」风格：通过专题主卡、标题与推荐理由建立浏览节奏。
- 发现页以学习目标、分级阅读、书单与学习路径组织内容。
- 使用长期有效的学习专题，避免依赖每日编辑更新。
- Zero to Hero 使用用户指定文章作为书单来源：https://mp.weixin.qq.com/s/U6lMD2kIQSIZsMXcBB15gg?scene=1
- 第一版支持官方书单、收藏书单、分级浏览和一条 Zero to Hero 路径；用户自建书单、社区和自适应推荐后续扩展。
- 本提案不等于已修改 App 或已更新在线预览。

## 2. 来源与学习体系

来源为向老师（向杨）的《一口气推荐100本英文原版书：向老师的Zero to Hero书单》，依据用户提供的完整正文整理。完整分组见 [来源书目附录](zero_to_hero_source_catalog.md)，结构化草稿见 [来源目录 JSON](data/zero_to_hero_source_catalog.json)。结构化草稿用于后续内容整理，不是已核验的可播放目录。

保留原文的初阶 8 级、中阶 6 级、高阶 4 级，共 18 级。初阶以儿童故事和小说为起点，中阶加入历史、哲学、社会科学，高阶走向学术和主题阅读。文章的词汇量建议作为“原文建议”说明，不设为强制门槛，不转换成 CEFR。

Zero to Hero 是该书单名称，原文入门建议词汇量为 1500 以上，并非零基础承诺。首页用“从儿童故事读向学术与思想”解释路径；首次选起点时说明这一前提。真正零基础用户不被自动导向原版长篇，明确说明当前路径需要一定基础。

原文的阶段体系、蓝思值、App 的 CEFR 词汇估算是三种不同信息。书单保持来源阶段顺序；难度浏览独立提供体系说明，缺失等级不强行补齐。

按出现位置整理，主线有 118 个条目（含中阶四级的 66 条主题资源），辅助线另有 3 条。此数不是去重作品数；不将文章标题的“100本”写成 App 精确库存。

中阶四级保留 7 个哲学主题组，作为阶段内资源池。用户按兴趣选择主题和本次计划，完成统计使用所选计划，不强制读完整个资源池。其余阶段也允许跳过或自行调整顺序。以上是 Lumina 的交互安排，不冒充来源的课程安排。

多本书在不同阶段重复出现。书目身份与阶段条目分离，保留每次出现的语境；只有版本和学习范围相同时才可提示复用已读状态，由用户确认，不将同名文本自动算成重复完成。

Hamilton 需核对剧本版本；中阶一级 Les Miserables 指剧本研读；Stories of Your Life 的题名、短篇与合集关系需核验。哲学部分的中文题名要先确认英语译本，不能直接拼接英文名或下载地址。

保留来源链接与署名，App 使用简短原创导读。原文演讲、写作、辩论、导师反馈和课程报名信息不进入 App 的功能承诺。文章推荐不代表 App 拥有相应文本或音频资源；逐版本确认后才开放导入或播放。

## 3. 发现页信息结构

### 页头

原生大标题「发现」，搜索入口，已收藏书单入口。首页先呈现学习内容，搜索结果中保留线上书籍、有声书、播客和本地书库范围切换；现有能力继续可达。

### 第一层：Zero to Hero 主专题

主卡使用 B 版的大标题、单一专题色和组合书封；副标题采用「找到起点，读向下一阶段」。首页展示“初阶 8 级 · 中阶 6 级 · 高阶 4 级”；书封素材与版本核实后使用。主操作为“找到我的起点”。

- 尚未加入：显示路径目标、适合人群、内容摘要，主操作「查看学习路径」。
- 已加入且有可用内容：显示当前阶段、最近学习条目、完成数量，主操作「继续学习」，次操作「查看路径」。
- 已完成：显示已完成条目数，提供「回顾书单」，不显示等级认证或“已精通”结论。
- 首屏主卡控制在手机可用视口约一半以内，让下一模块标题可见；标题和关键操作不覆盖在复杂书封文字上。

### 第二层：适合你的起点

初次提供自选大致水平与「不确定，先看看」入口，不强制测评。未选择水平时展示经过复核的通用入门书单；数据不足时不写「为你精准推荐」。选定后按等级、资源可用性及用户主动选择的目标做明确规则推荐。

### 第三层：按难度探索

使用等级入口和清晰的说明，区分「难度估算」「已复核」「出版物提供等级」。未知等级单独处理，不自动归为入门。路径阶段与 CEFR 等级分别存储，不能互相直接换算。

### 第四层：目标与兴趣书单

交替使用专题卡和紧凑书架，避免每个模块都使用巨幅海报。第一批可从来源目录派生「第一本英文原版」（初阶一级 4 本）、「故事里的奇想」（按兴趣从初阶段落选书）、「走近哲学」（中阶三级及中阶四级主题组）。派生书单需明确“Lumina 按主题整理”，不能称为原作者单独推荐的分组。难度跨度较大的主题卡不显示统一的“入门”标签。

每张书单卡显示标题、简短推荐理由、适合人群、书籍数量，以及适用时的等级范围。未知或不可核实的数据不显示。

### 第五层：探索全部内容

保留全部书库、搜索、资源类型浏览。书单是新增的发现方式，不替换现有来源搜索和导入流程。

## 4. 书单详情与学习路径

### 普通书单

详情按「标题与适合人群 → 一句推荐理由 → 收藏 → 有序书籍列表 → 来源说明」排列。用户可自由挑选；收藏整个书单不批量下载，也不自动将所有条目导入书架。书架增加「已收藏书单」入口。

### Zero to Hero 路径

详情按「路径简介 → 选择起点 → 阶段概览 → 当前阶段条目 → 全部阶段 → 来源说明」排列。阶段使用原文的“初阶一级”至“高阶四级”，配简短的 App 阅读目标；保持附录中的分组与出现顺序。

允许从任一合适阶段开始、跳过条目、回到前一阶段以及退出路径。默认推荐顺序，不做强制解锁。用户调整的是个人进度，不改写官方书单。

条目需分别表达学习状态和资源状态：

- 学习状态：未开始、进行中、已完成、已跳过。
- 资源状态：可导入文本、可收听、可匹配本地书籍、仅书目信息、暂不可用。

点击条目：已有本地版本则打开；可导入则进入现有详情和导入流程；无资源则显示书目信息与匹配本地文件入口，不展示无效播放按钮。

完成状态首先复用现有章节完成记录，按同一版本汇总；支持用户明确标记已读并记录来源。跳过不计为完成。完整读完仅表示条目完成，不表示语言能力达标。没有真实可核验数据时不承诺“若干天达到某级”。

## 5. 视觉与交互规范

- B 的编辑感来自标题、选题、对比和空间节奏，操作控件继续使用现有设计系统。
- 使用 AppDesignTokens、AppTextStyles、AppTheme 和 AppSectionHeader 等共享能力，不复制网页像素或新建平行主题。
- 专题色属于内容展示，收藏、继续学习等全局操作保持品牌色。浅色与暗色同步设计。
- 原生页面进入书单和阶段详情使用 push；起点选择和短筛选使用 sheet；退出路径保留正常返回路径。
- 以手机纵向单列为基准，宽屏再扩展主专题与辅助专题并排。支持大字号、长书名与缺失封面。
- 加载骨架匹配真实卡片结构；书单获取失败只影响该模块，缓存仍可浏览；单本资源失效不阻断整条路径。

## 6. 数据与实现方案

现状：项目已有 Gutendex、LibriVox 与本地书库发现入口、导入关联字段、章节完成记录，以及阅读难度字段。ReadingLevelEstimator 当前基于英语词汇样本估算 A1–B2，不覆盖完整阅读或听力能力，也不支持直接判定 C1/C2。

建议新增以下概念，实际类名在实施时遵循仓库约定：

| 实体 | 职责 |
| --- | --- |
| Collection | 官方书单标题、简介、适合人群、来源、修订版本 |
| CollectionItem | 书目引用、排序、简短推荐理由、来源位置 |
| LearningPath / PathStage | 路径、阶段顺序、阶段目标、阶段条目 |
| CatalogEntry / ResourceEdition | 作品书目与具体文本、简写版、音频版本及资源状态 |
| CollectionBookmark | 用户收藏关系 |
| PathEnrollment / ItemProgress | 当前阶段、加入时间、完成和跳过状态、完成依据 |

不要将尚未导入的推荐书强制写入当前本地 Book 模型。目录条目先通过 source + externalId 关联资源，再在导入后映射到本地 bookId；书名相同不能作为版本相同的依据。

等级元数据包括体系、等级、来源、适用版本和复核状态。无正文时不能用简介代替全文做等级估算。文本难度与音频信息分开记录。

第一版官方书单使用版本化配置文件随应用发布，避免先建设编辑后台；收藏与路径进度使用本地数据库。配置修订保留稳定条目 ID，更新顺序或删除条目时不丢失历史完成记录。跨设备同步与远程内容管理不包含在第一版。

## 7. 内容维护方式

将编辑工作收敛到一次性选书与周期性复核：

1. 按指定来源提取并核对 Zero to Hero 书目及顺序。
2. 核实版本和可用资源，标注未匹配条目。
3. 复核等级和适合人群；生成草稿可用自动化辅助，确认前不发布成官方结论。
4. 为书单写短简介、为条目写必要的推荐理由。
5. 页面根据结构化数据生成书封组合、数量和进度。

## 8. 实施顺序与验收

### 第一步：内容建模与视觉确认

原文书单已整理；下一步建立版本映射表；把现有 Web 提案收敛为 B 风格学习书店，覆盖发现页、书单详情和路径详情。书目可直接使用附录；版本和资源未核实时显示“资源待匹配”，不用虚构封面、时长或播放链接。

### 第二步：App 书单闭环

实现官方书单读取、详情、收藏、已收藏书单入口、等级浏览和资源导入关联。验收：可从发现页找到书单、收藏、选择实际条目并打开或导入；无资源时有清楚说明；现有搜索入口继续可用。

### 第三步：Zero to Hero 路径闭环

实现加入路径、选择起点、继续学习、完成和跳过、退出与恢复。验收：重启后进度保留；跳过不增加完成数；版本更新不清空进度；不会将完成状态显示为等级认证。

### 验证

按项目规范执行 Flutter analyze、相关 widget/数据库测试与 diff 检查。重点覆盖版本映射、完成统计、路径更新保留进度与资源失效。实际设备或模拟器检查浅色/暗色、窄屏、大字号、返回导航和完整交互。

## 9. 首屏与详情文案提案

- 辅助专题：把遇到的生词，带回下一次阅读。跳转当前词典收藏功能，不暗示已有间隔复习或完整词汇课程。
