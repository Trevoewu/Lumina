# Collaboration preferences

- Before answering a new request, first infer the intended outcome and restate it as a concise, clearer, executable prompt.
- If a material ambiguity could change the implementation or result, ask a focused follow-up question before acting.
- If the request is sufficiently clear, explicitly say that no clarification is needed and proceed without adding unnecessary questions.
- Informal or incomplete wording is acceptable. Help translate it into product, interaction, or engineering requirements while preserving the user's intent.
